# The 34 tools

<!-- eyebrow: Reference -->

*[Versión en español](../es/referencia.md) · [Tutorial index](../TUTORIAL.en.md)*

You do not call the tools yourself: the agent does. Knowing them helps you ask precisely and read what the agent does.
Each card says what the tool does, which study uses it, an example request and its parameters, with the description the
agent reads.

**The common filters.** Almost every analysis tool takes the same ones: `countries`, `library`, `date_from` and
`date_to` (a year, or a full date), `party`, `sex`, `speech_only` (speech only, by default), `exclude_chair` (without
whoever is in the chair) and `max_turn_words` (without the longest turns, nearly always documents read into the
record).
