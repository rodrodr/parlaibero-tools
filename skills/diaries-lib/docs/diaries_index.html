Pipeline de Diarios Parlamentarios · ParlaIbero

diaries-*

18 skills nativos de Claude Code que transforman diarios de sesiones parlamentarias —PDF escaneados o HTML— en matrices estandarizadas de intervenciones. Desde el OCR hasta el esquema canónico final, con un sistema de confianza de tres niveles que mantiene al investigador en control de cada decisión automática.

Sistema de confianza

AUTO · FLAG · HALT

● AUTO
≥ 0.85
umbral por defecto · ajustable por skill

El skill completó la tarea con alta confianza. El pipeline continúa automáticamente al siguiente paso sin ninguna intervención.

Sin acción requerida
◐ FLAG
≥ 0.65
umbral por defecto · ajustable por skill

El resultado es válido pero hay incertidumbre. El pipeline continúa y el caso se registra para revisión posterior en /diaries-review.

Revisar con /diaries-review
✕ HALT
< 0.65
umbral por defecto · ajustable por skill

La confianza es insuficiente para continuar o se produjo un error. El pipeline se detiene y se requiere intervención manual inmediata.

Intervención manual obligatoria
Fórmulas de confianza por skill
/diaries-ocr 0.7 × media_páginas + 0.3 × página_mínima
/diaries-tag  ⚠ 0.80/0.60 n_auto / (n_auto + n_sin_tag + n_llm × (1 − conf_llm))
/diaries-correct 1 − (correcciones_llm / párrafos_totales)
/diaries-match  ⚠ 0.90/0.70 n_vinculados_auto / n_oradores_únicos
/diaries-meta campos_extraídos / 5
/diaries-standardize 1 − (errores_validación / n_filas)
/diaries-matrix 1 − (bloques_sin_orador / bloques_totales)
/diaries-document 1.0 (determinista, sin LLM)

Comandos de control

/diaries-status

Muestra el estado actual del pipeline en tabla: skills × niveles (completo / flag / halt / pendiente) para todos los países activos.

/diaries-status --country {iso2}
/diaries-review

Revisión interactiva de casos FLAG. Para cada caso: muestra evidencia y confianza, y pide decisión: [A]ceptar · [C]orregir · [E]scalar · [S]altar.

/diaries-review --country {iso2}
/diaries-feedback

Inyecta una corrección en el estado. Tres tipos: punctual (1 sesión), rule (desde fecha → re-procesa), strategy (todo el skill + --force).

/diaries-feedback --country {iso2} --skill diaries-tag \
  --type rule \
  --description "Nuevo patrón de orador" \
  --pattern "^EL SR\." --action "tag_as_speaker" \
  --from 1931-09-01
/diaries-report

Genera el informe completo del proceso: línea temporal, distribuciones de confianza, historial de correcciones y tasa de automatización.

/diaries-report --country {iso2}
# Salida: docs/{iso2}/process_report.md
/diaries-teach

Guía interactiva del sistema. Ofrece 7 caminos: visión general, nuevo país, retomar pipeline, problemas por skill, sistema AUTO/FLAG/HALT, correcciones, mapa completo.

/diaries-teach
/diaries-refine

Mejora un skill a partir de una observación de testing real. Edita el SKILL.md en el repositorio, sincroniza a ~/.claude/skills/ y registra el cambio en REFINEMENTS.md.

/diaries-refine --skill diaries-tag \
  --issue "Los patrones multi-línea no se detectan"

/diaries-refine   # modo interactivo

Flujos de trabajo

Nuevo país desde cero

Para un código ISO2 que no existe aún en el sistema.

1
Colocar los archivos fuente
source/{iso2}/raw/YYYY-MM-DD.pdf
2
Configurar el país
/diaries-bootstrap --country {iso2}
3
Cadena de ingesta
/diaries-ocr --country {iso2} --all /diaries-extract --country {iso2} --all /diaries-correct --country {iso2} --all /diaries-review --country {iso2} /diaries-tag --country {iso2} --all /diaries-review --country {iso2} /diaries-meta --country {iso2} --all /diaries-matrix --country {iso2} --all
4
Resolución de entidades
/diaries-deputies --country {iso2} /diaries-match --country {iso2} /diaries-review --country {iso2}
5
Finalización
/diaries-merge --country {iso2} /diaries-standardize --country {iso2} /diaries-document --country {iso2} /diaries-report --country {iso2}
Retomar pipeline interrumpido

Cuando el proceso se detuvo por FLAGS sin resolver o un error HALT.

1
Diagnosticar el estado
/diaries-status --country {iso2}
2
Resolver FLAGs pendientes
/diaries-review --country {iso2}
3
Si hay un error sistemático, inyectar regla
/diaries-feedback --country {iso2} \ --skill diaries-tag \ --type rule \ --description "descripción del patrón" \ --from YYYY-MM-DD
4
Continuar desde el skill detenido
/{skill_detenido} --country {iso2} --all
Tip
Si no sabes por dónde empezar, /diaries-teach ofrece diagnóstico interactivo guiado paso a paso.
Configuración

Instalación

1 Clonar el repositorio

El repositorio incluye las utilidades Python y el instalador. Los 18 skills se mantienen aparte, en ~/.claude/skills/ (fuente única, versionada con git ahí).

git clone <repo-url> diaries
2 Ejecutar el instalador

Un único script instala las dependencias Python, verifica que los 18 skills estén en ~/.claude/skills/ y crea la estructura de directorios.

cd diaries
bash install.sh
3 Empezar

Abre Claude Code desde el directorio del repositorio y ejecuta la guía interactiva.

/diaries-teach

Skills · fuente única

Los 18 SKILL.md son la fuente única en ~/.claude/skills/diaries-*/ (versionada con git ahí, disponible a cualquier harness). No hay copia en el repo. Se editan directamente allí — p.ej. con /diaries-refine, cuyo cambio queda activo de inmediato y se registra en REFINEMENTS.md. No hay que copiar ni sincronizar.

Ollama · OCR local

Necesario solo para PDFs escaneados (pdf_image). El instalador avisa si falta.

ollama pull Maternion/LightOnOCR-2:1b  # primario
ollama pull glm-ocr                    # fallback
Estructura de directorios generada automáticamente

Al ejecutar /diaries-bootstrap por primera vez para un país, se crean todos los subdirectorios necesarios:

source/{iso2}/
├── raw/                  ← fuentes originales (tú las colocas)
├── ocr/{session_id}/     ← páginas OCR por sesión
├── extracted/            ← texto limpio (sin cabeceros/pies)
├── corrected/            ← párrafos corregidos
├── tagged/               ← texto con <int> tags
├── meta/                 ← JSON de metadatos
├── matrix/               ← interventions_raw.csv (acumulativo)
├── deputies/             ← deputies.csv
├── match/                ← matching_table.csv
├── merge/                ← interventions_enriched.csv
└── standardize/          ← {ISO2}_interventions.csv  (canónico ⚠)

docs/{iso2}/
├── README.md          ← documentación principal del corpus
├── data_dictionary.md ← diccionario de variables
├── dataset.jsonld     ← metadatos Schema.org (CC BY 4.0)
├── corpus_info.json   ← respuestas del procesador (reutilizable)
└── process_report.md  ← informe del proceso

El directorio docs/{iso2}/ es independiente de source/{iso2}/: la documentación de cada corpus nacional es un activo propio, separado de los datos de trabajo.

Lo que hace install.sh

✓ Verifica Python 3.11+
✓ Instala las 8 dependencias vía pip
✓ Verifica los 18 skills en ~/.claude/skills/ (fuente única; no los copia)
✓ Crea state/, source/, country_config/, docs/
✓ Verifica Ollama y modelos OCR disponibles
✓ Es idempotente: re-ejecútalo cuando quieras (no copia ni sincroniza skills)
