Árbol de procedimiento del pipeline ParlaIbero

Cada skill diaries-* con sus opciones de invocación, prerequisitos, condiciones de decisión y la acción que toma según cada rama. El hilo conductor es la puntuación de confianza, que cada skill convierte en estado del pipeline.

AUTO · complete FLAG · revisar HALT · detener SKIP · no aplica TEST / decisión artefacto E/S ERROR · aborta

Claude es el orquestador: lee cada SKILL.md, ejecuta las utilidades deterministas de lib/utils/, y resuelve con su juicio los casos ambiguos. Todos los skills de sesión aceptan --session · --batch · --all + --force · --dry-run.

Skills del pipeline — detalle de decisiones

0 diaries-bootstrap
Configura el país: audita lo ya hecho, infiere config, entrevista, inicializa estado nivel paíssolo --country
Paso 0 · Test de material fuente
¿Existe y no está vacío source/{iso2}/raw/?
vacío / no existe→ERRORaborta: «copia los archivos fuente antes de ejecutar»
hay archivos→lista session_ids (stem de cada archivo) y continúa
Paso 0b · Inventario de trabajo previo (por sesión y por país)
Para cada sesión comprueba qué etapas ya tienen output → celda OK / SKIP / . (pendiente). Clasifica:
ninguna etapa→sesión virgen → pending
algunas etapas con output→marca esas complete (detectado), resto pending
ocr/ vacío + formato digital/html→SKIP OCR (normal y correcto)
ya existe pipeline_state.json→NO sobreescribe: fusiona sesiones nuevas y actualiza pendientes detectadas
Paso 1 · Inferencia automática del formato (discriminador FIABLE)
¿Los archivos de análisis son raw o ya procesados?
corrected/ o extracted/→infiere formato del contenido o pregunta (confianza 0.70/1.0)
raw/ → assess_source.py→estructura por año (capa de imagen vía pdfimages), NO char-count
año DIGITAL→pdf_digital → texto embebido, OMITIR OCR
año ESCANEADO/MIXTO→pdf_image → capa OCR de calidad desconocida (ante duda: OCR)
⚠ Paso 1d — chequeo de integridad del prefijo de orador en escaneados: si garble_ratio > 0.40 con corrupción real (p.ej. SEROR≈SEÑOR) → source_format: pdf_poor_ocr, OCR obligatorio. (UY 1987: embebido detectó 14 intervenciones, OCR 164.)
Paso 2 · Entrevista dirigida
campo confianza < 0.80→muestra evidencia y pregunta (máx 8 preguntas)
usuario confirma regex→úsalo directo (confianza 1.0)
usuario dice «no sé»→deja needs_review: true
ya hay sesiones tagged→toma sus patrones como referencia y reduce la entrevista

2 diaries-extract
Consolida el raw en texto FIEL con marcadores de página — NO limpia (la limpieza entera es de diaries-correct) nivel sesión0.85 / 0.65
Paso 3b/3c · Mapeo source_format → modo de extracción
pdf_digital→pdf_digital — páginas vía fitz (paginado)
pdf_image / pdf_poor_ocr→ocr_pages — lee los page_*.txt ya producidos · NO reprocesa OCR
html / docx→html / docx — con sus trampas de encoding (charset declarado, mojibake por archivo)
xml (CL)→NO pasa por extract_text.py: parse_cl_xml.py — el XML ya viene TAGGED y MATCHED (id oficial de la Cámara como id_dep) → matriz por TURNO directa; esas sesiones entran al pipeline en el nivel de matrix (PT exigirá parser propio, esquema distinto)
doc (CL)→textutil -convert txt → tratar como text_flat
text_flat→text_flat — texto ya extraído; con page_break_marker segmenta por esa marca
La capa FIEL — conserva la frontera de página y NO se limpia nunca
---PAGE N--- en línea propia→se CONSERVA (extract.emit_page_marker, default true): es el ANCLA con la que correct quita el mobiliario
cabeceros / mobiliario / hifenación→NO se tocan aquí — --strip-headers queda como legado opt-in, fuera del flujo canónico
extracted/ como punto de retorno→cambiar una regla de limpieza NO obliga a volver a los binarios: se re-corre correct sobre extracted/; y meta lo consulta ÍNTEGRO (el cabecero por página trae los metadatos)
Paso 3e–3h · GATES de calidad (miden, NO limpian) → confianza y estado
confidence = valid_ratio si chars(salida) < 500 → confidence = min(confidence, 0.60) GATE 3f fragmentación: línea mediana < 25 car o cortes con guion > 2% → probar otro modo de extracción; si persiste, bajar confianza GATE 3g (escaneadas): garble_ratio > 0.50 en el prefijo de orador → confidence = min(confidence, 0.55) → HALT (re-OCR obligatorio) (sin lógica de cabeceros: en esta etapa no se limpia nada)
AUTO≥ 0.85 y sin alertas
FLAG0.65–0.85 · o fragmentación persistente
HALT< 0.65 · prefijo OCR corrupto
Gate de salida del batch: > 2% de archivos con < 200 bytes → PARA e investiga el formato. Trampas por origen: charset DECLARADO del HTML, elementos void, el <p> VACÍO como frontera de párrafo, mojibake 2× (PT) y DOCX heterogéneo por archivo.

3 diaries-correct
El ÚNICO limpiador: secuencia de 5 pasos + bucle de residuo + deshifenización de 2ª pasada nivel sesión0.85 / 0.65
Rediseño 2026-08: correct es el ÚNICO limpiador. extract entrega extracted/ fiel y SIN limpiar (con los ---PAGE N--- conservados); TODA la eliminación de cabeceros, folios, mobiliario e hifenización ocurre aquí, una sola vez. Tres partes: Paso 0b DESCUBRIR el mobiliario del país (por frecuencia, por década → country_config) → Paso 2 APLICAR → Paso 2-R VERIFICAR EL RESIDUO en bucle.
Secuencia canónica de limpieza — 5 pasos, orden obligatorio
1 · identificar el separador de página→---PAGE N--- (o el del país): el ANCLA de todo lo demás
2 · eliminar el mobiliario→anclado al separador — CINCO clases: furniture_block/line/masthead/prefix/inline; masthead con keep-first; NUNCA borrar Prolegomena
3 · eliminar el separador→solo AHORA, ya vacío de mobiliario (quitarlo antes deja el mobiliario huérfano)
4 · aislar los marcadores de orador→línea en blanco delante de cada speaker_tag_patterns: frontera dura que el paso 5 no cruza
5 · restaurar la fluidez→deshifenizar y unir las líneas de caja DENTRO de cada turno, sin cruzar los marcadores del paso 4
El separador, el mobiliario y el marcador son DE CADA PAÍS: se DESCUBREN leyendo su texto (y por década), se GUARDAN en su country_config y se VERIFICAN antes de promover. Nunca en bloque, nunca adivinando ni reusando los de otro país.
Paso 2c/2d · Pase determinista + resolución LLM de saltos ambiguos
correct_text.py --config: corre los 5 pasos con el vocabulario del país; protege los marcadores en el merge y los reensambla (marker_reassembly · marker_join_next con condición de CIERRE — patrones SIMÉTRICOS en género). Devuelve furniture_removed, marker_joins y ambiguous_breaks.
salto = artefacto (corte de columna/justificación)→une las dos partes con Edit
salto = párrafo real (fin de oración + mayúscula)→no toca nada
batch --all masivo→NO se resuelven uno a uno (son mayormente legítimos): pase determinista + confianza por integridad
Gates 2d-bis / 2d-ter · el marcador ni PARTIDO ni ENTERRADO
residuo de marcadores partidos ≠ ~0→no avanzar a tag: añadir el patrón a marker_join_next y re-correr (PY: saltárselo costó ~100.000 turnos, el 25% del corpus)
caída de marcadores > 2% por sesión (extracted vs corrected)→HALT la sesión: el acumulador ENTERRÓ marcadores (BR −28%); el −N ES la señal — verificar con patrones vacíos es ciego
Paso 2-R · Bucle de residuo de mobiliario (supervisado)
descubrir → aplicar → verificar residuo → refinar … hasta ~0 DOS detectores: (1) limpiar_mobiliario --medir (patrones conocidos) (2) INDEPENDIENTE por frecuencia: líneas idénticas que recurren en >20% de sesiones y no cierran frase — no comparte léxico con el config ⚠ un 0 limpio es SOSPECHOSO hasta explicarlo (corpus aplanado no se ve)
Paso 2-quater · Deshifenización de 2ª pasada sobre corrected/ completo
deshifenizar.py --textdir — léxico del PROPIO corpus, no un diccionario externo: une el guion+salto residual y el guion+ESPACIO (~209 k solo en ES). La variante espacio exige evidencia positiva del léxico y CONSERVA lo ambiguo. Primero --medir, luego aplicar.
Paso 2e · Confianza — por INTEGRIDAD, no por ratio de ambiguos
⚠ NO usar ratio_ambiguous como proxy: es alto POR GÉNERO del texto (orden del día, listas, marcadores) → FLAG masivo falso si out_chars ≥ 0.80·in_chars y total_paragraphs > 0 y out_chars > 300 → confidence = 0.95 → complete si no (pérdida de contenido / salida vacía o minúscula) → confidence = 0.60 → flag
Salida
source/{iso2}/corrected/{id}.txt
4 diaries-meta
Metadatos: fecha, nº de sesión, tipo, legislatura y la PRESIDENCIA por TRAMOS 0.85 / 0.65
Posición: justo después de diaries-correct, antes de diaries-tag. Su insumo es extracted/{id}.txt — la capa FIEL: los metadatos de sesión viven a menudo en el cabecero de cada página, que diaries-correct elimina; corrected/ queda solo como respaldo por sesión concreta. Ejecutarlo aquí es lo que permite que diaries-dedupe elimine los escaneos duplicados antes de la fase de etiquetado. Además, la presidencia por TRAMOS que extrae (presidency.segments) es el insumo del Paso 3-bis de diaries-merge, que atribuye los roles de mesa sin nombre.
⚠ Paso 0 obligatorio: usar la heurística registrada del país (meta_patterns) o DESCUBRIRLA — muestra de 40 documentos repartidos por TODO el período, validada con cuatro señales (resuelve contra el padrón · contigüidad temporal · cardinalidad · reparto por género). Los regex se anclan a la fórmula de cabecera de la sesión (no a la 1ª fecha del texto, que suele ser un acta/decreto citado). El parser de meses debe cubrir variantes locales (setiembre) y el ordinal de día (1º).
Paso 0c-bis · Presidencia por TRAMOS — no un único presidente
⚠ «Un presidente por sesión» falla el 35,0% de los casos (medido): la presidencia cambia de manos DENTRO de la sesión. Meta registra la SECUENCIA de quién preside y en qué tramo (presidency.segments), no un solo nombre; president (singular) se mantiene por compatibilidad y se DERIVA — es la apertura, segments[0].name.
mesa de la carátula/Prolegomena→presidente de APERTURA (via: prolegomena) + candidatos a relevo (vicepresidentes, secretarios)
relevos anunciados en el CUERPO→patrón DESCUBIERTO por país («Ocupa la Presidencia el señor X»…) → via: relevo
«reasume la Presidencia» sin nombre→via: back_to_base — el centinela que devuelve la mesa al titular; sin registrarlo, el tramo del vice no se cierra nunca
scope del país→presidency.scope: session | segments en el country_config — lo consume attribute_presidency.py aguas abajo
Prioridad de fuentes de date (mayor → menor autoridad)
1 · cabecero corrido (voto mayoritario)→MÁXIMA autoridad: repetido en cada página, robusto
2 · masthead de portada→válido solo si el cabecero lo corrobora (único punto de fallo)
3 · nombre de archivo (session_id)→ÚLTIMO RECURSO, puede tener errores; nunca gana al cabecero
Paso 2d · Resolución de date por voto del cabecero corrido
cabecero = nombre (≥2 votos)→el masthead era el error → AUTO
cabecero = nombre − 1 día→nombre corrido +1 → adopta fecha del cabecero (date≠session_id) → AUTO
mismatch/fallback NO resuelto por el cabecero→nunca AUTO → FLAG (revisión)
sin fecha en cabecero, masthead ni nombre→HALT
Paso 2e · Confianza ponderada (5 campos × 0.20)
cada campo: regex → 0.20 | LLM → 0.17 | no encontrado → 0.0 confidence = Σ contribuciones de {date, session_number, session_type, legislature, president} (el override de date manda sobre el resultado del peso)
Salida
source/{iso2}/meta/{id}.json
5 diaries-dedupe
Duplicados en DOS clases: (A) misma sesión bajo >1 session_id · (B) filas dobladas por ingesta multi-track — antes de tag boletín + fecha
Va ANTES de diaries-tag, no antes de matrix (corregido 2026-07-24). Su único insumo es meta.date, y diaries-meta lee extracted/ (la capa fiel): nada obliga a esperar al etiquetado. Hacerlo después tiene un coste de corrección, no solo de tiempo — el Paso 0c de diaries-tag rankea las formas de marcador por frecuencia sobre TODO el corpus para decidir cuáles entran al léxico; con sesiones duplicadas dentro, sus formas se cuentan dos veces y esa calibración sale sesgada. Deduplicar después ya no lo arregla.
⚠ Imprescindible antes de matrix: sin esto, los escaneos duplicados doblan el conteo de intervenciones. Señal fiable = nº de boletín + fecha real verificada por el día de la semana; el contenido (Jaccard) da falsos negativos por distinta calidad OCR.
Clase A · Decisión por grupo de sesiones (boletín + fecha real)
mismo boletín ∧ misma fecha real→DUPLICADO → cuarentena (conserva el keeper)
mismo día, boletín distinto→sesiones legítimas (mañana/tarde) → intactas
mismo boletín, fecha real distinta, contenido no similar→boletín OCR mal leído → revisar, no se toca
Clase B · Paso 1-bis — filas DOBLADAS dentro de una sesión (solo ingesta multi-track)
desplazamiento CONSTANTE de intervention_order→detector preferente: la firma inequívoca de la ingesta doble, sin umbrales (CO 2007-05-02: pares todos a 526 de distancia)
solapamiento ≥ 70% · 25–70%→duplicada / parcial → deduplicar fila a fila (conserva: con id_dep → texto más largo → track de calidad MEDIDA en ese país)
solapamiento < 25%→complementaria, NO es duplicado — no tocar. NUNCA descartar una copia entera (CL: ninguna contenía a la otra; la «peor» era la mejor)
siempre→informa y pide confirmación explícita, incluso con --write/--yes; tras deduplicar, renumerar intervention_order (1-based y continuo)
Cuarentena reversible + estado POR SESIÓN
Clase A: redundantes → source/{iso2}/_quarantine_duplicates/ (corrected,tagged,extracted,meta,ocr,raw) manifest.json: redundant → keeper · restaurar = mover de vuelta · idempotente Clase B: filas retiradas → standardize/{ISO2}_quarantine_intrasesion_dups.csv (nunca se borran) Estado POR SESIÓN (no _country): cada redundante → skipped · cada keeper → complete
Salida
source/{iso2}/_quarantine_duplicates/ + manifest.json standardize/{ISO2}_quarantine_intrasesion_dups.csv (clase B)
6 diaries-tag ⚠
Etiqueta oradores — skill crítico, dos niveles de detección 0.80 / 0.60
Prerequisito: el corpus debe estar YA deduplicado (meta → dedupe → tag). Si el país trae pase de lista nominal, construye además el padrón antes de tagear (diaries-deputies, ruta del pase de lista) y pásalo con --deputies: mejora el scoring del nivel 2 probabilístico. Antes esa mejora era inalcanzable porque el padrón se construía cuatro pasos después.
El honorífico y el terminador son específicos de cada país y cambian por OCR/era/taquígrafo. Paso 0 obligatorio: discover_speaker_patterns.py descubre las formas por su FORMA — el vocabulario nunca se adivina (falló en SV y dos veces en GT). Punto de partida: docs/_metodologia/FASE_C_MARCADORES_POR_PAIS.md — terminadores, clases de marcador y variantes OCR ya pagados; el descubrimiento los CONFIRMA y amplía, no los reinventa. Semilla de terminadores por país: : (ES·GT·EC) · .— (UY — ignorarlo enterró 7.851 marcadores) · .- (grafía OCR del anterior, EC) · — standalone (PT); tolerancia OCR: se\S{1,2}or (seflor, sefior…), EL→FL (EC), H.D.→HE. (PA). Paso 0b obligatorio la 1ª vez: analyze_speaker_markers.py descubre variantes/errores antes de tagear.
Las CINCO clases de marcador — cada una con tratamiento propio
FORMAL→núcleo VERSAL + terminador del país (:, .—…) — la única clase que abre turno (produce <int>)
APARTE→interjección entre paréntesis DENTRO del turno de otro — NO abre turno; se separa como turno propio solo si hay TEXTO delante, no por distancia (BR: 18.718)
MENCIÓN→Titlecase + verbo en el discurso («el señor García afirma…») — ignorar; el discriminador frente al turno real es el núcleo VERSAL
VOTO nominal→«Por el señor Diputado X», listas de votación — NO abre turno: tag.vote_patterns lo EXCLUYE del tagging y diaries-matrix declara esas filas dm_speech = 0
NARRATIVA→el orador va en una CLÁUSULA en prosa, no en un núcleo versal (DO, CO) — modo propio tagging_style: narrative; el speaker_raw se NORMALIZA a la persona, no a la frase
Paso 2c/2d · Detección de dos niveles + LLM
NIVEL 1 estricto (speaker_tag_patterns)→marcador canónico; guion [-–—] (OCR usa em-dash) → etiqueta directa
NIVEL 2 score ≥ 0.60→etiqueta (recupera ~5% de terminadores irregulares)
NIVEL 2 score ∈ [0.40, 0.60)→caso límite → FLAG / resolución LLM
span sospechoso (untagged)→LLM decide orador (inserta <int speaker>) o lo descarta
Paso 2e · Confianza + guardia estructural
confidence = n_auto / (n_auto + n_untagged + n_llm·(1 − avg_llm_conf)) si n_auto + n_untagged + n_llm == 0 → confidence = 0.50 (sesión sin oradores: sospechosa) GUARDIA (fuente escaneada): si source_format ∈ {pdf_poor_ocr, pdf_image} y chars > 5000 y n_auto < 3 → confidence = min(confidence, 0.50) «prefijo de orador corrompido por OCR embebido → re-OCR obligatorio»
AUTOconfidence ≥ 0.80
FLAG0.60 ≤ confidence < 0.80
HALTconfidence < 0.60

7 diaries-matrix
Parse de texto etiquetado → filas CSV (determinista) nivel sesión
Gate de entrada + Paso 3a/3b · Prerequisitos y auditoría previa
diaries-tag con sesiones en HALT (falsos negativos)→ABSOLUTE FAIL — NO construir la matriz: un marcador sin etiquetar atribuye su intervención entera al orador anterior; volver a /diaries-tag
falta tagged/ o meta/→HALT, informa qué falta
n_tags <int> == 0 en fuente→HALT: archivo sin etiquetas válidas
intervention_format→auto · inline (<int speaker>) · standalone (PT)
Paso 3e/3f · Cobertura de tags (salvaguarda anti-bug del parser)
tasa_cobertura = (interventions_added + filtered_short) / n_tags_fuente confianza = 1 − untagged_blocks / (interventions_added + untagged_blocks) si tasa_cobertura < 0.80 → confianza = min(confianza, tasa_cobertura)
completeconfianza ≥ 0.80
FLAGconfianza < 0.80 · o cobertura < 0.50
HALTcobertura < 0.20 (fallo sistemático)
Paso 5 · Auditoría de marcadores INCRUSTADOS en el text (gate de salida)
ratio ≤ 0,1%→aceptable (residuo de OCR irreducible) → split_embedded_markers.py divide las filas residuales y recupera el turno (parte del flujo, decidido 2026-08-23)
